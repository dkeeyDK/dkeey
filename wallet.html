Wallet

Connect a Solana wallet to see your address and balance. This page only reads. It never signs or sends anything.

Read this first

  • There is no DKEEY token or presale yet. There is nothing to buy.
  • We never ask for seed phrases or private keys. Never type them anywhere.
  • This page does not save your address. It asks a public Solana node for your balance and token list, so that node can see your IP address and the address you connect.
