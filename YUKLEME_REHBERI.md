# Bugünün tüm dosyaları - GitHub'a yükleme (tarayıcıdan)
Klasör içeriği: LICENSE, NOTICE, README.md (Apache-2.0), wallet.html, support.html, docs/ (9 belge), research/ (benzetimler), public-good/ (açık kaynak paketi).
1. github.com/dkeeyDK/dkeey -> giriş.
2. "Add file" -> "Upload files".
3. Bu klasörün İÇİNDEKİLERİ sürükleyin (klasörler alt klasörleriyle gelir). YUKLEME_REHBERI.md'yi yüklemeyin.
4. Aynı adlı dosyalar (LICENSE, README.md, docs içindekiler) üzerine yazılır: istenen budur.
5. Commit mesajı: "Apache-2.0, wallet page, support page, research and docs" -> "Commit changes".
6. Kontrol: ana sayfada "Apache-2.0 license"; kökte wallet.html ve support.html.
Site ayrıca: wallet.html ve support.html siteye yüklenince dkeey.com/wallet.html ve /support.html açılır (siteniz GitHub depodan yayınlanıyorsa). Menüye henüz bağlantı eklemedim; bilerek.
